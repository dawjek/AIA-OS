# Zaplecze techniczne

Tu są skrypty pamięci, procedury i miejsca na materiały robocze. Narzędzia pamięci wymagają Python 3.10+, a lokalny Brain Node.js 22+. Kod i publiczne instrukcje są częścią startera. Dane użytkownika, wygenerowane pakiety, plany, audyty i wyniki należą do prywatnej instalacji. Przed aktualizacją paczki zachowaj kopię prywatnych plików.
