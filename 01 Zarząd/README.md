# Zarządzanie pracą

Tu jest mapa projektów, decyzje dotyczące całego systemu i rytm przeglądów. Główna rozmowa AI korzysta najpierw z prywatnego `PORTFOLIO.md`, potem z karty i dokumentu stanu właściwego projektu. W czystej paczce istnieje tylko [wzór portfolio](PORTFOLIO.template.md). Onboarding tworzy plik użytkownika bez `.template`.

Nie trzeba zakładać firmy ani zespołu. „Zarząd” oznacza tutaj miejsce na własne decyzje i priorytety. Sam plan nie potwierdza ukończenia pracy; zapisuj wynik, dowód i następny krok.
