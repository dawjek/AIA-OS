# AIA-OS w Claude Code

Przeczytaj [START.md](START.md) i [wspólną instrukcję](.ai/instructions/shared.md), jeśli nie są już w kontekście. Pisz po polsku. System jest dla różnych rodzajów pracy; folder klientów może pozostać pusty.

Gdy użytkownik prosi o pierwszą konfigurację albo jej wznowienie, zastosuj [start](.ai/skills/start/SKILL.md). Skille dostępne dla Claude są w `.claude/skills/`, a ich kanon w `.ai/skills/`. Jeśli sesja nie udostępnia nazwanego skilla, przeczytaj jego plik z kanonu i wykonaj go samodzielnie; nie udawaj załadowanego narzędzia.

Własne dane użytkownika zapisuj w lokalnych plikach bez `.template` według [zasad pamięci](.ai/instructions/memory.md). Nie zmieniaj publicznych README i szablonów na prywatne notatki. Do działania poza lokalnym folderem stosuj zakres upoważnienia z bieżącej rozmowy. Po pracy podaj, co zapisano, co sprawdzono i czego nie potwierdzono.
