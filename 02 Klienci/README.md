# Klienci

Ten folder jest opcjonalny. Jeżeli pracujesz dla klientów, załóż osobny katalog dla każdego rzeczywistego zlecenia, dodaj dokument stanu i wpis w prywatnym portfolio. Dane klienta zapisuj tylko w jego prywatnym folderze. Jeśli nie pracujesz z klientami, zostaw ten folder z samą instrukcją.
