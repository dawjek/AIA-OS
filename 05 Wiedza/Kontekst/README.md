# Kontekst użytkownika

Onboarding tworzy prywatne pliki z poniższych wzorów:

- [profil i współpraca](wlasciciel.template.md);
- [cele i priorytety](priorytety.template.md);
- [mapa pracy](mapa-pracy.template.md);
- [stan rozmowy](stan-rozmowy.template.md);
- [działalność](firma.template.md), jeśli jest potrzebna.

Pakiet `pakiet-startowy.md` jest generowany przez pamięć po skonfigurowaniu źródeł. Nie wpisuj do niego ręcznie decyzji. Użytkownik może czytać i poprawiać prywatne źródła, a potem przebudować pakiet.
