# Wiedza i kontekst

`Kontekst/` zawiera to, co asystent powinien wiedzieć na początku pracy: profil, cele i mapę źródeł. `Wiki/` przechowuje opracowane, bardziej trwałe wnioski ze wskazaniem pochodzenia. Bieżący stan projektu, terminy i liczby sprawdzaj w jego własnym źródle. Szablony są publiczne; właściwe dokumenty użytkownika powstają po konfiguracji i są prywatne.
