# Połączenia

To wzór prywatnego `polaczenia.md`, który powstaje podczas konfiguracji. Zapisuj nazwy usług i sposób dostępu, ale nie hasła, tokeny ani kody odzyskiwania.

| Usługa lub narzędzie | Do czego służy | Stan | Gdzie sprawdzić dostęp |
|---|---|---|---|
|  |  | nieskonfigurowane |  |

Stan „połączone” wpisz dopiero po rzeczywistym sprawdzeniu dostępu. Samo posiadanie konta lub konfiguracji nie potwierdza działania integracji.
